Objetivo PrincipalDesenvolver uma página web didática e interativa para explicar conceitos de fluxo de trabalho e formar os novos elementos da equipa, para que consigam perceber as bases num espaço de 5 a 10 minutos.   Requisitos FuncionaisExplicação de métricas: A ferramenta deve mostrar e explicar métricas importantes do sistema, tais como o cycle time (tempo de ciclo), o lead time, o throughput e a quantidade de trabalho em simultâneo.   Gráficos Cumulativos: É obrigatório incluir um gráfico cumulativo que mostre o estado das tarefas ao longo do tempo. A página deve ensinar como interpretar este gráfico para que o utilizador seja capaz de identificar problemas ou estrangulamentos por si mesmo.   Simulador: O sistema deve incluir uma funcionalidade que permita realizar simulações, para que seja possível observar o que acontece quando se aumenta ou diminui a quantidade de trabalhos em simultâneo.   Quizzes interativos: Devem ser incluídos pequenos questionários de forma dinâmica ("porreira") para que o utilizador consiga validar rapidamente os conhecimentos adquiridos.   Chat integrado: É necessário incorporar um chat preparado para responder às perguntas dos utilizadores, integrando a informação e os conhecimentos abordados pelo professor Ricardo.   Restrições e Contexto do NegócioA priorização de tarefas não é o foco principal deste projeto, uma vez que o problema real do cliente é a dispersão e a perda de foco provocadas pela acumulação de múltiplas tarefas curtas que ficam inacabadas.   Como entregável imediato, o cliente espera receber uma pequena proposta com ideias ou layouts visuais.   No final da sessão de hoje, a equipa deverá ter pronto o planeamento da primeira Sprint, que será executada ao longo da semana.
